# Security policy

## Supported versions

Security fixes are released for the latest 1.x version.

## Reporting a vulnerability

Please don't open a public issue. Email **atoausten@duck.com** instead, with:

- what the problem is and what an attacker could do with it
- steps to reproduce it, or a proof of concept
- the package version, and your Laravel and PHP versions

You'll get a reply within a few days. Once a fix is released, the changelog
will credit you, unless you'd rather stay anonymous.

If the problem is in Paystack itself rather than this package, report it to
Paystack as well.
